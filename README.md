# codeforge-privacy

Static privacy-policy pages for Chrome extensions, meant for GitHub Pages at
`https://sidharthvijayan.github.io/codeforge-privacy/`.

- `/jsonld-inspector/` → JSON-LD Structured Data Inspector
- `/hreflang-canonical-checker/` → Hreflang & Canonical Checker

To publish (not done yet): create the public repo `SidharthVijayan/codeforge-privacy`, push `main`, enable Pages (branch `main`, root).
