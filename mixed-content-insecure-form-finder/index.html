Privacy Policy for Mixed Content & Insecure Form Finder

Effective date: November 5, 2026  ·  Last updated: November 5, 2026

Summary

Mixed Content & Insecure Form Finder finds the insecure http:// addresses and http form actions in the web page you are viewing, entirely inside your browser. It does not collect, store, sell, or transmit any personal data, browsing history, or page content.

What the extension accesses

Only when you click the extension's button, it reads the current tab's address, protocol and title; the web addresses (with query strings and fragments removed) used by the page's scripts, stylesheets, iframes, frames, objects, embeds, images, picture sources, video, audio and CSS written in the page; a short description of the element using each one (its tag, id and first class name); and, for each form, its action address, method, number of fields and whether it has a password field. It also checks whether the page sets an upgrade-insecure-requests policy. It does not read anything you have typed into forms, the page's text, cookies, or other tabs, and it does not visit or download any of the addresses. This "website content" is processed in memory in the extension's popup and is discarded when the popup closes.

Permissions and why they are needed

  • activeTab: grants temporary access to the tab you are on, only after you click the extension. It gives no access to other tabs or to sites in the background.
  • scripting: runs a small read-only script in that tab, once per click, to read the addresses listed above. It does not change the page.

When you press "Copy", the report is placed on your clipboard using that click; the extension does not read your clipboard. When you press "Download file", the file is created in your browser and saved through Chrome's normal download, without the downloads permission.

Data sharing

No data is sent to the developer or any third party. The extension makes no network requests, uses no analytics and loads no remote code.

Data retention

Nothing is stored by the extension, including your chosen export format; it lasts only while the popup is open. The only copy of the data is any file you choose to download or text you choose to copy. The extension uses no cookies, local storage, or sync storage.

Changes

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
