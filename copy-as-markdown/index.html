Privacy Policy for Copy as Markdown

Effective date: November 15, 2026  ·  Last updated: November 15, 2026

Summary

Copy as Markdown turns the part of a web page you selected into Markdown entirely inside your browser. It does not collect, store, sell, or transmit any personal data, browsing history, or page content.

What the extension accesses

Only when you click the extension's button, it reads the current tab's address and title and the part of the page you have selected, with its headings, links, lists, tables, code and image addresses. If nothing is selected, it reads the page's main article instead. It skips hidden text, scripts and form fields, and it does not read anything you have typed into forms, cookies, or other tabs. This "website content" is turned into Markdown in memory in the extension's popup and is discarded when the popup closes.

Permissions and why they are needed

  • activeTab: grants temporary access to the tab you are on, only after you click the extension. It gives no access to other tabs or to sites in the background.
  • scripting: runs a small read-only script in that tab, once per click, to read the selected part of the page as described above. It does not change the page or your selection.

When you press "Copy Markdown", the text is placed on your clipboard using that click; the extension does not read your clipboard. When you press "Download .md", your browser saves the file to your downloads folder like any other download.

Data sharing

No data is sent to the developer or any third party. The extension makes no network requests, uses no analytics and loads no remote code. Links and image addresses in the Markdown are written as text; the extension does not open or load them.

Data retention

Nothing is stored by the extension; results last only while the popup is open, and options are not saved. The only copies of the data are any text you choose to copy or file you choose to download. The extension uses no cookies, local storage, or sync storage.

Changes

If this policy changes, the updated version will be posted on this page with a new "Last updated" date.
